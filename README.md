# Практическая работа №2 — инфраструктура проекта

Учебный проект StudyTasks по дисциплине «Инструменты DevOps».

## Цель

Настроить локальный и удалённый Git-репозитории, структуру проекта, документацию и список задач.

## Структура

- `src/` — исходный код;
- `tests/` — автоматические тесты;
- `docs/` — документация проекта;
- `TASKS.md` — список задач;
- `reports/` — отчёт;
- `.gitignore` — исключения Git.

## Запуск

```bash
python3 -m src.main list
```

## Тестирование

```bash
python3 -m unittest discover -s tests -v
```
