# Соответствие методическим указаниям

Контрольная №1 в СДО: https://online-edu.mirea.ru/mod/assign/view.php?id=931533

Прикреплённый файл `Практическая работа №1-2.docx` содержит задание на инфраструктуру: публичный репозиторий, доска или список задач, документация, локальный Git, связь с удалённым репозиторием, основные файлы, push и отчёт Word со скриншотами и ссылкой.

Дополнительно использованы актуальные `Практическая работа №1.pdf` и `Практическая работа №2.pdf` из раздела практических занятий: https://online-edu.mirea.ru/mod/folder/view.php?id=931531. В этих документах указан 2026/2027 учебный год; во вложении контрольной сохранился 2025/2026 год.

По актуальным материалам подготовлены about_me.md, goals.md, hobby.md в feature-ветке, заметки IDE/CLI, сравнение SVN, ответы на вопросы и локальная ветка для rebase. Парное ревью требует отдельного участника; его статус указывается в отчёте и PR без имитации чужого одобрения.

Список TASKS.md выбран как разрешённая методичкой альтернатива GitHub Projects; папка docs служит разделом документации. Исходные методички доступны через СДО и не перепубликуются в публичный репозиторий.
