# Документация StudyTasks

StudyTasks — учебный планировщик задач в командной строке. Он помогает хранить список работ и отмечать выполненные пункты. Проект используется для изучения Git, GitHub и автоматизации разработки на дисциплине «Инструменты Девопс».

## Пользовательские сценарии

1. Студент добавляет задачу с непустым названием и получает её номер.
2. Студент просматривает задачи с отметками выполнения.
3. Студент отмечает задачу выполненной по её номеру.
4. После перезапуска программы задачи сохраняются в JSON.

## Структура и требования

- `src/main.py` — CLI, проверка данных и хранение задач.
- `tests/test_cli.py` — интеграционные проверки жизненного цикла и ошибочных данных.
- `data/tasks.json` — локальные данные пользователя, исключённые из Git.
- `docs/` — описание проекта и порядок работы.
- `reports/` — отчёт по контрольной и подтверждающие скриншоты.
- Python 3.10 или новее, дополнительных пакетов не требуется.

## Запуск

Из корня репозитория:

```bash
python3 -m src.main add "Подготовить контрольную по DevOps"
python3 -m src.main list
python3 -m src.main done 1
python3 -m unittest discover -s tests -v
```

Путь к хранилищу можно изменить: `python3 -m src.main --file /tmp/study-tasks.json list`.

## Критерии готовности

Задачи сохраняются между запусками; пустые названия и неизвестные номера отклоняются; повреждённое хранилище не перезаписывается; три интеграционные проверки проходят; инструкции воспроизводимы.

## Ограничения текущей версии

Программа рассчитана на одного пользователя и последовательные запуски. Одновременная запись несколькими процессами, сетевой API, авторизация и резервное копирование не реализованы. Дедлайны, Docker и CI запланированы отдельно.

## Процесс разработки

Новая задача → отдельная ветка → осмысленные коммиты → проверка тестами → Pull Request → ревью → исправления → squash merge → удаление рабочей ветки. Начальная загрузка каркаса выделена в отдельный PR.

Доска задач находится в [TASKS.md](../TASKS.md); актуальное обсуждение и состояния задач — в [GitHub Issues](https://github.com/blur3773/devops-course-2026/issues).
