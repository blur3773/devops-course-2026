# Мой пет-проект

**Название:** StudyTasks — учебный планировщик задач.

**Идея:** консольная программа, которая сохраняет учебные задачи в JSON, показывает список и позволяет отметить выполненную работу.

**Стек:** Python 3.10+, стандартные библиотеки argparse, json и pathlib; Git и GitHub; unittest для тестирования.

**Цель:** освоить GitHub Flow и воспроизводимую разработку небольшой программы, а на следующих занятиях добавить Docker и CI/CD.

**Первая версия:** добавление, просмотр и завершение задач, сохранение данных между запусками, проверка ошибочного ввода.

**Критерий готовности:** три интеграционные проверки проходят; README содержит команды запуска.
