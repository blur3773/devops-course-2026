# Цели на семестр

1. Освоить GitHub Flow: для каждой новой возможности создавать ветку и Pull Request, исправлять замечания ревью и разрешать конфликты.
2. Упаковать учебный планировщик в Docker и обеспечить воспроизводимый запуск одной командой.
3. Настроить GitHub Actions так, чтобы при каждом Pull Request автоматически выполнялись проверки и тесты, а ошибки блокировали выпуск.
