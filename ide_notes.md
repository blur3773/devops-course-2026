# Работа с Git в VS Code и терминале

## Три удобные возможности VS Code

1. Source Control объединяет изменённые файлы, индексацию и ввод сообщения коммита в одной панели. Коммит `docs: define hobby project acceptance criteria` выполнен через интерфейс VS Code.
2. Редактор diff показывает исходную и новую версии hobby.md рядом; добавленная строка с критерием готовности выделена цветом. Скриншот сохранён в отчёте.
3. Встроенный Graph отображает коммиты и ветки рядом с изменениями, а установленный GitLens дополняет редактор аннотациями авторства строк.

## Что удобнее в терминале

Интерактивный rebase: команда `git rebase -i HEAD~3` явно задаёт диапазон и позволяет воспроизводимо объединить нужные коммиты в отдельной локальной ветке. CLI также удобен для сохранения вывода команд и запуска тестов.

Эти заметки закоммичены и отправлены через CLI в отдельной ветке с последующим PR в main.
